

# Pins

## Naming

SPI pins are often called by different names accoding to different vendors or designers. Here is a small guide to the names used.

Pin:
- Clock
	- SCLK = Serial Clock
	- SCK = Serial Clock
	- CLK = Clock
	- SPICLK = SPI Clock
- Master Out / Slave In
	- MOSI = Master Out Slave In
	- SDA = Serial Data
	- SDI = Serial Data In
	- DIN = Data In
- Master In / Slave Out
	- MISO = Master In Slave Out
	- SDO = Serial Data Out
	- DOUT = Data Out
- Chip Select
	- CS = Chip Select
	- CE = Chip Enable
	- SS = Slave Select
